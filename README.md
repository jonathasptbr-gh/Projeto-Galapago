# Projeto Galápago

Jogo indie mobile de criaturas: você vive e envelhece junto de uma criatura
com personalidade própria, que evolui pelo que vive — e o laboratório da ilha
está testando **você**.

- Motor: Godot 4.7.2 · Arte: pixel art via PixelLab
- Conceito: [`docs/CONCEITO.md`](docs/CONCEITO.md)
- Para quem desenvolve (humano ou agente): [`AGENTS.md`](AGENTS.md)

```bash
tools/estado.sh    # o estado medido
tools/testes.sh    # testes headless
tools/quadros.sh   # grava quadros da cena (oráculo visual)
```

Todos os direitos reservados.
